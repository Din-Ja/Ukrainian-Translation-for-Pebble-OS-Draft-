# Ukrainian-Translation-for-Pebble-OS-Draft-
Hi everyone!
I have been working on a Ukrainian translation of the Pebble smartwatch interface for some time. I am certainly not a professional translator, but I think I have finally reached a point where the result is good enough to share with others.
I tested the translation on a Pebble Time 2 running firmware version 4.44.1.
Because of the small watch screen, I sometimes had to use shorter words and phrases, and not all translations may be ideal. However, overall, I am quite happy with the result.
In recent firmware versions, the developers added horizontal text scrolling for menu titles. This solved the problem with longer Ukrainian phrases that previously did not fit on the screen. There are still some untranslated menu items, but this seems to be a firmware issue rather than a translation issue, as all translation strings have been translated. I hope this will be fixed in future updates.
Getting the font right also took quite a bit of work. I spent a lot of time adjusting it, and I think the result looks pretty good now.
There are also some issues that are not related to the translation itself, but rather to Cyrillic character rendering. For example, in notifications with the Larger text size, the lowercase Cyrillic letter "з" is currently displayed as a heart symbol instead of the correct letter. I have already reported this issue to the developer and hope it will be fixed.
I also haven't been able to check some words, phrases and sentences in the menus, as well as some font sizes, simply because I haven't yet found where they are displayed. So there may still be some things that need improvement.
I hope to keep working on this translation and eventually make it as good as possible.
In the meantime, if you are interested, feel free to use this translation! Enjoy! 😉
